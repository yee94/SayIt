# Product Brief: SayIt

## Executive Summary

SayIt 是一款跨平台桌面语音输入工具，目标是让使用者在任何应用程式中透过一个按键即可将语音转为整理过的简体中文书面文字。产品以「开箱即用」为核心设计原则 — 安装后设定一组 API Key，按住快捷键就能用。转录结果经由 AI 自动去除口语赘词、修正标点、适当分段，直接贴入游标位置。初期为个人效率工具，中期目标扩展至公司内部使用。

---

## Core Vision

### Problem Statement

开发者与知识工作者在日常工作中有大量文字输入需求（Slack 讯息、PR 描述、会议笔记、文件撰写等），但打字速度远跟不上思考速度。语音输入是自然的解决方案，但现有工具要么功能复杂需要大量设定（VoiceInk 需管理本地模型、多种提供商），要么需要付费订阅（Typeless），要么辨识品质不足以直接使用（macOS 内建听写没有 AI 后处理，输出充满口语赘词）。

### Problem Impact

- 思考到文字的转换摩擦导致想法流失或表达品质下降
- 反复打字造成效率低落，尤其在需要快速回复或记录的场景
- 现有语音输入的原始输出不够「干净」，使用者仍需手动编辑，抵消了效率增益

### Why Existing Solutions Fall Short

| 方案 | 问题 |
|------|------|
| macOS 内建听写 | 无 AI 后处理，口语赘词保留，标点不准确，无法直接作为书面文字使用 |
| VoiceInk | 功能强大但设定繁复（12+ AI 提供商、本地模型管理、Power Mode），「自己动手组装」的体验 |
| Typeless | 需付费订阅，有免费额度限制 |
| 通用语音转文字 API | 需要自己写程式串接，不是终端使用者产品 |

所有现有方案都缺少一个关键组合：**零设定的语音输入 + 自动 AI 书面语整理 + 全域贴上**，三者无缝合一。

### Proposed Solution

一个常驻在系统列的桌面应用程式，核心流程只有一步：按住快捷键说话，放开后文字自动出现在游标位置。背后由 Groq Whisper API 完成语音辨识，再经 Groq LLM 以可自订的 prompt 将口语转为通顺的简体中文书面语。搭配自订词汇字典提升专业术语辨识率，历史记录提供使用统计与回顾能力。

### Key Differentiators

1. **极简设计哲学** — 设定只有三项：快捷键、API Key、AI Prompt。不提供不必要的选项，刻意排除语言切换、多提供商、分阶段文字处理等复杂功能
2. **AI 即后处理** — 不做多阶段文字管线，一次 AI 呼叫搞定去口语、分段、标点全部事情。使用者只需要调整一段 prompt 就能控制所有行为
3. **跨平台开箱即用** — Tauri v2 架构，macOS 和 Windows 各有最佳预设（mac: Fn / win: 右 Alt），不需要使用者理解平台差异
4. **从自用到团队** — 先为自己打造最顺手的工具，验证后可推广至公司内部，零学习成本

## Target Users

**Persona 1：Jackle — 全端工程师（产品发起人）**

**Persona 2：Mia — 产品经理**

- **痛点：** 会议后需要快速整理笔记、回复大量 Slack 讯息、撰写需求文件，打字效率限制产出量

## Success Metrics

### User Success Metrics

| 指标 | 目标 | 衡量方式 |
|------|------|---------|
| **输出可用率** | > 90% 的转录结果不需要手动修改即可直接使用 | 使用者主观回馈 + 观察是否触发 undo/修改 |
| **日活使用率** | 部署后 > 80% 的使用者每个工作日都会使用 | Dashboard 历史记录（每日有记录的使用者数） |
| **端到端延迟** | 放开按键到文字出现 < 3 秒（含 AI 整理） | 历史记录中 `transcriptionDurationMs + enhancementDurationMs` |
| **首次使用时间** | 从安装到第一次成功语音输入 < 2 分钟 | Onboarding 流程观察 |

### Business Objectives

纯内部效率工具，不涉及营收指标。核心目标：

1. **提升团队文字输入效率** — 减少打字时间，让团队成员把时间花在思考而非输入
2. **降低导入门槛** — 非技术角色也能零学习成本上手，不需要 IT 支援
3. **稳定可靠** — 作为日常工具，稳定性比功能丰富度重要

### Key Performance Indicators

| KPI | 目标值 | 时间框架 |
|-----|--------|---------|
| 日均使用次数（每人） | >= 10 次 | 部署后 1 个月 |
| 团队采用率 | > 80% 日活 | 部署后 2 周 |
| AI 整理输出满意度 | 不需修改率 > 90% | 持续追踪 |
| 累计节省时间 | Dashboard 可见 | 持续累计 |
| 系统可用率 | > 99%（排除网路问题） | 持续追踪 |

## MVP Scope

### Core Features

| # | 功能 | 说明 |
|---|------|------|
| 1 | **跨平台热键系统** | `rdev` crate 统一监听，macOS 预设 Fn、Windows 预设右 Alt，可自选修饰键，支援 Hold + Toggle 双模式 |
| 2 | **AI 文字整理** | 转录文字送 Groq LLM + 可编辑 prompt，一次完成去口语、分段、标点修正。字数 < 10 字跳过 AI 直接贴上 |
| 3 | **自订词汇字典** | CRUD 管理常用词汇，注入 Whisper API prompt 提升辨识率，同时注入 AI 上下文 |
| 4 | **历史记录** | SQLite 持久化每笔转录（原始文字、整理后文字、时长、字数等），供 Dashboard 统计与回顾 |
| 5 | **App UI — Dashboard** | 统计卡片（总口述时间 / 字数 / 节省时间 / 速度 / 使用次数 / AI 使用率）+ 最近转录列表 |
| 6 | **App UI — 历史 / 字典 / 设定** | 历史记录搜寻与复制、词汇 CRUD、快捷键设定 / Groq API Key / AI Prompt 编辑 |
| 7 | **HUD 状态扩展** | 新增 `enhancing` 状态，完整状态机：idle → recording → transcribing → enhancing → success/error → idle |

### Out of Scope for MVP

| 项目 | 原因 | 预计阶段 |
|------|------|---------|
| VAD 静音侦测 | 需 Web Audio API 研究，Toggle 模式先以手动停止为主 | Phase 2 |
| 串流转录（即时字幕） | 需 WebSocket 整合，核心体验已够用 | Phase 2 |
| Mini HUD 模式 | 外接萤幕适配，优先级低 | Phase 2 |
| 剪贴簿还原 | 目前不还原已确认可接受 | Phase 2 |
| 多 AI 提供商 | 仅 Groq，避免过度设计 | 未定 |
| 多语言切换 | 输出统一简体中文 | 未定 |
| Per-App 设定（Power Mode） | VoiceInk 风格，复杂度高 | 未定 |
| IT 统一部署管理 | 先个人安装模式 | 未定 |

### MVP Success Criteria

MVP 达成以下条件即视为成功，可进入 Phase 2：

1. **核心流程可用** — 按键 → 录音 → 转录 → AI 整理 → 贴上，端到端延迟 < 3 秒
2. **跨平台运作** — macOS 和 Windows 上都能正常使用
3. **输出品质** — > 90% 的转录结果可直接使用，不需要手动修改
4. **团队可部署** — 公司同事能在 2 分钟内完成安装并开始使用
5. **资料可追踪** — Dashboard 正确显示使用统计

### Future Vision

**Phase 2 — 体验优化：**
- VAD 静音侦测搭配 Toggle 模式，实现真正的免手动语音输入
- 串流转录即时字幕，边说边看
- Mini HUD 适配外接萤幕

**长期方向：**
- Per-App 智慧设定（不同 App 自动切换 prompt）
- 多语言支援（英文、日文等）
- IT 集中管理（API Key 统一配置、使用量监控）
- 考量是否开源或转为公司产品
